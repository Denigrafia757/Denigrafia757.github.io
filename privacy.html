Политика конфиденциальности

Настоящая страница описывает общий порядок обработки персональных данных при использовании сайта «Домстрой».

1. Какие данные может предоставить пользователь

При заполнении формы обратной связи пользователь может указать имя, номер телефона, сведения об участке, желаемую площадь и комментарий по проекту. Поля формы используются для подготовки обращения и расчёта строительства.

2. Согласие на обработку персональных данных

Перед отправкой формы пользователь самостоятельно подтверждает согласие на обработку персональных данных, устанавливая отдельный флажок. Согласие является добровольным и может быть отозвано в порядке, предусмотренном законодательством Российской Федерации.

3. Цель и порядок обработки

Цель обработки — рассмотрение обращения пользователя, связь с ним по вопросу строительства и подготовка информации по проекту. Данные обрабатываются только в объёме, необходимом для указанной цели, если иное не предусмотрено законодательством Российской Федерации.

4. Передача данных во внешние сервисы

После заполнения формы сайт формирует текст обращения. Пользователь самостоятельно подтверждает дальнейшую передачу сообщения во внешнем сервисе Telegram. Обработка данных Telegram осуществляется по правилам соответствующего сервиса.

5. Фотографии и материалы

Фотографии и иные материалы на сайте используются для демонстрации проектов и результатов строительства.

6. Изменения

Информация на этой странице может обновляться при изменении функциональности сайта или порядка работы с обращениями.
