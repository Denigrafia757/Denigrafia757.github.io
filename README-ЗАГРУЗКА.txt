ДОМСТРОЙ — ФИНАЛЬНАЯ ВЕРСИЯ САЙТА

1. Распакуйте архив.
2. Загрузите ВСЕ файлы и папки из этой папки в корень репозитория GitHub Pages.
3. Файл CNAME НЕ УДАЛЯЙТЕ — он нужен для домена.
4. После загрузки подождите, пока GitHub Pages соберёт сайт.
5. Откройте сайт в приватной вкладке браузера и проверьте мобильную и компьютерную версии.

В архиве нет старых цен и старых рекламных обещаний.
Оригинальный логотип Домстрой подключён из вашего GitHub-репозитория.
